# Требования для AI Design Generator

## Проект: **MusicFlow — Music Streaming Service**

Создай современный, premium-level дизайн музыкального стримингового сервиса уровня Spotify / Apple Music / Deezer с акцентом на immersive music experience, clean UX и эмоциональный visual storytelling.

---

# 1. Общая дизайн-концепция

### Стиль

* Modern music streaming platform
* Premium dark UI
* Minimalistic but emotional
* Glassmorphism + soft gradients
* Smooth rounded corners
* Cinematic lighting accents
* Clean typography hierarchy
* Focus on album artwork

### Визуальное настроение

* Атмосфера late-night music session
* Premium entertainment product
* Энергия музыкальной платформы
* Immersive feeling
* High contrast UI
* Elegant animations

### Inspirations

* Spotify
* Apple Music
* Tidal
* SoundCloud
* Linear
* Framer

---

# 2. Цветовая палитра

### Основная тема

* Dark theme as default
* Deep black / graphite backgrounds
* Accent neon colors

### Основные цвета

* Background: #0B0B0F
* Surface: #15151D
* Elevated cards: #1D1D27
* Primary accent: vibrant purple / electric blue
* Secondary accent: pink gradients
* Text primary: #FFFFFF
* Text secondary: #A0A0B3

### Эффекты

* Soft glow around active elements
* Gradient overlays on album covers
* Blur backgrounds for player and modals
* Hover lighting effects

---

# 3. Типографика

### Стиль шрифтов

* Modern sans-serif
* Bold headings
* Compact readable body text

### Иерархия

* Hero titles: large and bold
* Section titles: medium-large
* Track titles: semibold
* Metadata: smaller muted text

### Визуальные требования

* Excellent readability on dark backgrounds
* Tight but elegant spacing
* Spotify-like typography rhythm

---

# 4. Layout System

### Общая структура

* Sticky sidebar navigation
* Main scrollable content area
* Persistent bottom music player
* Responsive adaptive grid

### Desktop Layout

* Sidebar width: 240–280px
* Content centered with max-width
* Large horizontal music carousels
* Multi-column cards

### Mobile Layout

* Bottom tab navigation
* Swipe-friendly interactions
* Full-width cards
* Floating player mini-bar

### Spacing

* Generous whitespace
* 8px spacing system
* Consistent paddings and margins
